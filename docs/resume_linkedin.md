## C. LinkedIn project description

Designed and developed a cloud-based Student Assignment Submission & Feedback Portal that digitizes the complete assignment lifecycle. Students can register, view deadlines, upload and resubmit assignments, track status and view feedback. Teachers can create coursework, review files, grade submissions and return feedback.

The project uses React + Vite with Firebase Authentication, Cloud Firestore, Firebase Cloud Storage and Firebase Hosting. I also added an optional FastAPI REST layer, Firebase Cloud Functions v2 processing for deadline/version analytics, local Firebase emulation, automated testing and GitHub Actions CI. The architecture emphasizes separation of structured metadata from object storage, role-based authorization, query-safe Security Rules, environment-based secrets and scalable cloud design patterns.
